# Moss Landing (Peaks) Wave Height Prediction Using XGBoost Regression

## Motivation

This project asks the scientific question: **Can local surf wave height at Moss Landing (Peaks) be predicted from offshore buoy data, nearshore CDIP wave model data, tide conditions, and historical surf observations?** This question is important because surf height at a specific break can differ from raw offshore swell or model forecasts due to local bathymetry, tide effects, swell direction, and nearshore transformation. A site-specific prediction model could help improve surf forecasts for Moss Landing by learning how historical observations relate to environmental wave inputs. Better local forecasts are useful for surfers, coastal recreation planning, and understanding how offshore wave energy changes as it reaches the shoreline.

## Data

The dataset used for this project consists of historical surf observations for **Moss Landing (Peaks)**, stored in an Excel workbook named `Peaks Surfing DATA.xlsx`, along with optional processed CSV files generated by the notebook. The raw observation file contains date/time information, observed surf-height notes, and swell descriptions that are parsed into numerical wave-height and swell-feature columns. Additional environmental inputs are pulled or prepared from public coastal data sources such as CDIP wave data and NOAA tide predictions; CDIP data can be accessed from the CDIP public data portal, and NOAA tide predictions can be accessed from the NOAA CO-OPS API. The dataset is small enough to include in a GitHub repository if permitted, and it is stored primarily as `.xlsx` and `.csv` files, with model outputs saved as `.csv`, `.json`, and `.joblib` files.

Data source links:
- CDIP public data portal: https://cdip.ucsd.edu/
- NOAA CO-OPS API: https://api.tidesandcurrents.noaa.gov/api/prod/
- Project observation data: `Peaks Surfing DATA.xlsx` in this repository

## Model

This project uses an **XGBoost regression model** to predict observed wave height in feet at Moss Landing (Peaks). XGBoost is appropriate for this question because it can model nonlinear relationships between surf height and environmental inputs such as swell height, swell period, direction, tide, and nearshore wave model values. Unlike a simple linear regression, XGBoost can learn interactions between variables, such as how a certain swell direction may produce larger surf only during certain tide or period conditions. The model is trained using historical observations where the target variable is the observed surf height, `observed_hs_ft`. The main loss function used during training and evaluation is **root mean squared error**, or RMSE, which penalizes larger prediction errors and is useful for continuous wave-height prediction. Additional metrics such as MAE, MSE, R², bias, and median absolute error are also used to understand model performance.

## Analysis

Model results will be evaluated using a time-based holdout set, where the most recent portion of the observations is reserved for testing and not used during training. This approach tests whether the model can predict newer surf conditions from older training examples, which is more realistic than randomly mixing past and future observations. Performance will be analyzed using regression metrics including MAE, RMSE, R², and bias, along with plots comparing actual versus predicted wave heights and residual errors. The notebook also includes binned wave-height accuracy and a confusion matrix to evaluate whether the model correctly classifies surf into practical size categories.
